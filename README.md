# App web de gestion de budget

Mini application web (HTML/CSS/JS) pour gérer des ventes de services et de produits.

## Fonctionnalités

- Ajout d'une vente (service/produit) avec montant, coût, encaissement, date de vente, date de prélèvement.
- Calcul automatique de :
  - Chiffre d'affaires total.
  - Bénéfice total.
  - Créances restantes (montants non encore encaissés).
- Tableau récapitulatif des ventes enregistrées.

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir : <http://localhost:8000>
